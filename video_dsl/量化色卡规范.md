# 量化色卡规范（v3.1）

> 视觉权威文件之一：定义 7 个颜色枚举 token 与内建主题。
> 配套契约：`video_dsl/concept-video-dsl.md`（数据契约）、`video_dsl/schema/concept-video.schema.json`（机器校验）。

---

## 1. 颜色 token（封闭 7 枚举）

全系统只允许以下 7 个颜色 token。场景、特效参数、素材引用中出现颜色时**只能引用 token**：

| token | 语义 | 典型用途 |
|---|---|---|
| `primary` | 主色 | 标题强调、主视觉、关键数字 |
| `secondary` | 次色 | 次级信息、辅助图形、弱化文本 |
| `accent` | 点缀色 | 高亮标记、装饰元素、引导视线 |
| `success` | 正向色 | 上涨/收益/正确/达成 |
| `warning` | 警示色 | 风险提示、注意区、临界值 |
| `danger` | 负向色 | 下跌/亏损/错误/回撤 |
| `neutral` | 中性色 | 正文、边框、背景层次、网格线 |

## 3. token 引用纪律

- **场景内禁裸 hex**：`scenes[]` 内任何字段（含分镜 `style.colors`、特效 `background.params`、素材描述）都不得出现 hex 色值，只能写 token 名；
- **hex 唯一合法出现处**：顶层 `style.colors`——且只能以 7 个 token 为键重定义其值（`^#[0-9A-Fa-f]{6}$`），相当于在文件内自定义色卡；
- **分镜 `style.colors` 是重映射而非重定义**：值为 token 名（如 `colors: { primary: danger }`），把主色临时映射为另一 token；
- 素材生成（imagegen）prompt 需注入当前生效的色板描述，保证插画与主题色一致；
- 校验：`style.colors` 的键集合与 hex 格式由 JSON Schema 机器把关；场景内裸 hex 由 schema（分镜 colors 值仅接受 token 枚举）+ 语义复查共同拦截。
